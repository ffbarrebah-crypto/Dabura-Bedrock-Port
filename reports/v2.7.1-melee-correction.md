# Dabura melee correction — v2.7.1

## Scope
This is a source-level correction against the v2.7.0 phase-3 candidate. The packaged add-on is built locally as `Jujutsu_SailorK_Daboura_Kavra_v2.7.1_melee-fix.mcaddon`.

## Changes made
1. `Daboura_Kavra_BP/scripts/ai.js`: replaced the close-range AI gates. Previously the NPC's deterministic jab required no prior light opener and no recent damage; cross required recent damage; Combo 1 required at least one light opener. These conditions could leave melee to the weighted picker while ranged techniques remained eligible. The new priority is:
   - Combo 1 when grounded and 1.2–5.5 blocks away, if the normal cast guard permits it.
   - Heavy cross within 3.2 blocks after recent damage, if available.
   - Quick jab within 2.8 blocks, if available.
   - Existing kick and counter rules remain below these checks.
2. `Daboura_Kavra_BP/scripts/main.js`: added a native `entityHitEntity` event for players in Dabura form. A successful ordinary melee hit triggers a quick jab, or a heavy cross if the jab is cooling down, with an 8-tick input debounce. This makes a normal melee connection an input for Dabura's custom punch rather than requiring the technique menu for every punch.
3. Bumped BP and RP manifest versions from 2.6.1 to 2.7.1 so the package version matches the candidate build.

## Important limitation
This is static/local validation only. It has not been run inside Minecraft Bedrock 1.26.40. The native-hit event is an after-event, so vanilla melee damage can occur before the custom jab/cross; the custom attack adds its own damage and animation. In-game balance, event availability in the target runtime, and actual AI behavior still require a Minecraft test. Do not treat this report as proof of in-game success.
